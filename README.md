# customer-service-agent

# 產品客服 Agent 學習文件

## 一、應用場景
我認為顧客希望能隨時得到即時回覆，但人工客服有上班時間限制、
且大量重複性問題（如運費、退換貨、出貨進度）會浪費很多客服人力。
本 Agent 目標是打造一個 24 小時線上的產品客服助理，能自動回答
顧客常見問題、查詢訂單與退換貨流程，減輕人工客服負擔，
讓真人客服可以專注處理較複雜的個案。

## 二、Agent 初步構想
- 服務對象：網路商店的一般消費者
- 主要任務：回答常見問題、查詢出貨進度、說明退換貨政策、引導下單
- 使用平台：Coze
- 觸發方式：使用者在網頁或 LINE 上輸入問題後可以自動回應

## 三、核心名詞與知識結構
- **AI Agent**：能自主感知輸入、進行判斷並執行任務的 AI 應用
- **拖拉式（No-code）**：不需撰寫程式碼，透過拖拉節點就能建立流程
- **Coze**：本單元使用的 Agent 建構平台，可視覺化組裝對話流程
- **Workflow / 節點**：串接「使用者輸入 → 判斷 → 回應」的流程單元

## 四、本週學習心得

我就可以組出一個能對話的客服助理，讓我對無程式碼開發有了具體認識。
過程中比較不熟悉的是 GitHub 的 Repo 建立，README 上傳流程之前就有處理過，
但這次也有讓我練習到之前沒練習過的東西。
